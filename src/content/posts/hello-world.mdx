This is the first post on the new site. It's written in [MDX](https://mdxjs.com), which means regular markdown works as expected, but I can also drop in React components when I want something more than text — like a chart.

Here's a `BarChart` component embedded directly in this post:

<BarChart
  title="Example data"
  data={[
    { label: "Mon", value: 12 },
    { label: "Tue", value: 18 },
    { label: "Wed", value: 9 },
    { label: "Thu", value: 24 },
    { label: "Fri", value: 15 },
  ]}
/>
